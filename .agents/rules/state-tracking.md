# Rule: State Tracking & Handover
Setiap kali Anda selesai menulis/mengubah kode, atau sebelum tugas Anda dialihkan/selesai, Anda WAJIB memperbarui file `AGENTS.md` di root folder dengan format berikut:
1. **Current Status**: Apa yang baru saja selesai dikerjakan.
2. **Pending Tasks**: Apa yang belum selesai dan harus dilanjutkan.
3. **Architectural Decisions**: Alasan memilih pendekatan kode tersebut.
4. **Active Diffs**: Lokasi file yang baru saja dimodifikasi.
